# Part 3: Written Responses

1. Question 5 is a case the pipeline should answer correctly: its result is `winner: "Outlaws"` and `score: "128-110"`. It resolves to one authoritative game row after matching two teams and a date. Question 4 is the failure case: the final output should say `"answerable": false`. The Outlaws’ first game can be identified, but it has no player_box_scores row for Deshawn Carver, so returning a number would fabricate evidence. The difference is that the first question has every required source row, while the second has a missing required player-game row. With another day, I would improve `build_working_set` and its structured retrieval query with explicit diagnostic metadata explaining which required join was absent, then show that reason in the user-facing response.

2. I would add player tracking data. A coach could ask, “Which lineup gives up the largest average corner-three separation after a defensive switch?” Box scores and recaps cannot answer that. I would store possession-level events with game, lineup, player, timestamp, court coordinates, and derived features such as nearest-defender distance. I would retrieve candidate possessions with metadata filters, then aggregate in SQL or a columnar analytics store; clip review and a held-out play-label set would validate the result. The current design breaks because it embeds one textual document per row and asks an LLM to reason over it. Sixty frames per second across ten players is too large and numeric for that pattern. Embeddings would help retrieve annotated clips, but geometric computation and aggregation need a dedicated feature pipeline.

3. I would be most excited to work with strategy. It sits where scouting, performance, and game context become concrete decisions: matchups, coverage choices, and lineup combinations. I enjoy building tools that make evidence easy to inspect rather than treating a model’s output as an answer by itself. A strategy group would let me pair reliable data pipelines and video or tracking context with interfaces that coaches can challenge quickly. The feedback loop is compelling because I can measure whether a question was useful, whether the evidence was trustworthy, and whether the recommendation improved preparation or execution. That combination of technical rigor and direct basketball impact is what I find most motivating.
